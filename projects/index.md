# Engineering projects

Current systems presented through problems, decisions, evidence, and capability boundaries.

## Featured work

### [Slater: private, voice-first AI assistant]({{ '/projects/slater/' | relative_url }})

A distributed, locally hosted assistant built around one chat core, capability boundaries, tool orchestration, evaluation replay, voice and MCP interfaces, and explicit trust controls.

**Topics:** Local LLMs · agent tools · context engineering · evaluation · MCP · voice · security

### [Agentic software engineering automation]({{ '/projects/agentic-software-engineering/' | relative_url }})

A human-governed workflow for decomposing engineering requests, retrieving organizational context, modifying repositories, integrating with GitHub, and processing review feedback.

**Topics:** Coding agents · planning · GitHub · human approval · enterprise integration

### [AI request triage agent]({{ '/projects/request-triage-agent/' | relative_url }})

An evidence-grounded Python agent for request analysis, tool use, structured resolution, evaluation, and explicit escalation.

**Topics:** Python · tool invocation · structured outputs · evaluation · observability
